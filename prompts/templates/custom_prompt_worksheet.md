## 🎯 Example: Completed Worksheet for "Magic Spell System"

*See next page for an example of a completed worksheet to guide you...*

### Example Feature: Magic Spell System

**Feature Name:** Magic Spell System

**One sentence description:** Add the ability to learn and cast magical spells with different effects.

**Why it's cool:** Magic makes the game more fantasy-like and gives players cool abilities to use!

**Difficulty:** 🟡 Medium

**Prerequisites:**
- ✅ Base game working
- ✅ Inventory system (for spell scrolls)
- ✅ Combat system (some spells useful in combat)

**Commands players will type:**
1. "learn [spell]" - learn a new spell from a scroll
2. "cast [spell]" - cast a learned spell
3. "spells" - list known spells

**What happens:**
1. Learn spell - adds spell to known_spells list
2. Cast spell - applies spell effect (heal, attack, unlock door)
3. Spells command - shows list with descriptions

**Variables needed:**
- known_spells: list - stores spells player has learned
- spell_effects: dictionary - maps spell names to what they do

**Core requirements:**
1. Track which spells player knows (list)
2. Learn spells from scrolls found in rooms
3. Cast spells with different effects
4. Each spell can only be cast once (consumed)
5. Show helpful messages

**Test plan:**
1. Find scroll, type "learn fireball" → spell added to known_spells
2. Type "spells" → shows fireball with description
3. Type "cast fireball" → fireball effect happens, removed from known_spells
4. Type "cast fireball" again → message saying "You don't know that spell"
