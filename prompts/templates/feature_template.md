## 📝 Template Instructions

When creating a new prompt using this template:

1. **Replace all [bracketed text]** with your specific content
2. **Choose appropriate difficulty level** (🟢/🟡/🔴)
3. **Be specific in requirements** - vague prompts get vague results
4. **Include testing checklists** - help students verify it works
5. **Provide extension ideas** - support different skill levels
6. **Add common issues** - help with debugging
7. **Think about learning** - what concepts does this teach?
8. **Keep it beginner-friendly** - use simple language
9. **Test your prompt with AI** - make sure it generates working code
10. **Share with class** - help others learn from your feature!

## 💡 Tips for Writing Good Prompts

### DO:
- ✅ Be specific about what you want
- ✅ Give context about what's already working
- ✅ Ask for beginner-friendly code
- ✅ Request explanations with the code
- ✅ Specify code style requirements
- ✅ Include examples if helpful

### DON'T:
- ❌ Be vague ("make it better")
- ❌ Skip prerequisites
- ❌ Forget to mention you're a beginner
- ❌ Ask for overly complex features
- ❌ Copy code without understanding it
